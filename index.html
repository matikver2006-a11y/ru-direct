Российские сайты — мимо VPN

Госуслуги, банки, маркетплейсы и всё российское — напрямую, остальное — через VPN. Включили VPN один раз и не выключаете. Для Happ — одной кнопкой, для других VPN-приложений — инструкции ниже.

Happ

Открыть сразу в Happ
  1. Нажмите «Скопировать».
  2. Откройте Happ → «+» → «Вставить из буфера обмена» → согласитесь добавить маршрутизацию «RU мимо VPN».
  3. Выключите и снова включите VPN.

Проверка: откройте yandex.ru/internet — там должна быть Россия. (Некоторые VPN-сервисы специально пускают 2ip.ru через VPN — по нему не проверяйте.)
Если профиль уже стоит — сначала удалите старый в настройках маршрутизации Happ.

Свои сайты

Не открывается какой-то российский сайт? Добавьте его адрес и скопируйте профиль заново.

Другой VPN

Готовые списки: 512 российских доменов и 8 652 российские подсети. Всё на .ru, .su, .рф входит целиком.

Hiddify
  1. Настройки → Регион → Россия (ru).
  2. Переподключитесь.

Встроенная функция приложения. Название пункта меню может немного отличаться в вашей версии.

v2rayNG (Android)
  1. Нажмите
  2. Настройки → Маршрутизация → меню ⋮ → Импорт правил из буфера обмена.
  3. Там же: Стратегия доменов → IPIfNonMatch.

Правило по IP использует geoip:ru из стандартного файла geoip.dat приложения.

Streisand (iPhone)

Настройки → Маршрутизация → добавьте правила с выходом direct:

domain:ru
domain:su
domain:xn--p1ai
geoip:ru
geoip:private

Полный список geosite на iPhone лучше не включать: приложению не хватает памяти.

Shadowrocket (iPhone)

Конфигурация → ⓘ у активного конфига → Правила → +. Добавьте выше финального правила:

DOMAIN-SUFFIX,ru,DIRECT
DOMAIN-SUFFIX,su,DIRECT
DOMAIN-SUFFIX,xn--p1ai,DIRECT
GEOIP,RU,DIRECT
Полный список правил
Clash Verge Rev, FlClash, Clash Meta (mihomo)

Правила нужно добавить в начало, до финального MATCH подписки. В Clash Verge Rev: Глобальное расширение конфигурации (Merge) — вставьте файл целиком; для одной подписки — правой кнопкой → Редактировать правила.

sing-box, Karing

Karing: при первой настройке выберите страну Россия — включатся правила «geoip:ru и geosite:ru напрямую».

sing-box: фрагмент route с официальными наборами правил SagerNet:

sing-box-route.json
Amnezia VPN
  1. Откройте iplist.opencck.org, выберите формат Amnezia и тип IPv4 (CIDR), скачайте файл.
  2. В Amnezia: Раздельное туннелирование → режим «Сайты не через VPN» → ⋮ → Заменить список сайтов → выберите файл.

Amnezia запоминает IP домена один раз, поэтому списки подсетей надёжнее списков сайтов.
